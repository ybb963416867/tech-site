# 启动优化工具选择

## traceview

- 图形的形式展示执行时间、调用栈等
- 信息全面，包括所有的线程
- 运行时开销严重，整体都会变慢
- 可能会带骗优化方向
- traceview（可以在代码中买点）与cpu profiler（分析）
- 使用方式

1. Debug.startMethodTracing("");
2. Debug.stopMethodTracing();
3. 生成的文件在sd卡： Android/data/packagename/files

## systrace

- 结合Android内核的数据，生成Html报告
- API18 以上使用，推荐TraceCompat
- 使用方式

1. python systrace.py -t 10 [other-options] [categories]
2. https://developer.android.com/studio/command-line/systrace#command_options
3. 开始位置调用：TraceCompat.beginSection("ApponCreate");
4. 结束位置调用：TraceCompat.endSection();

- 轻量级，开销小
- 直观反映cpu利用率
- cputime与walltime区别

1. walltime是代码执行的时间
2. cputime是代码消耗cpu的时间（重点指标）
3. 举例：锁冲突

## 注意

两种方式互相补充

正确认识工具及不同场景选择合适的工具
