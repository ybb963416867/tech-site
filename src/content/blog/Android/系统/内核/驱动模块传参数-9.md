# 驱动模块传参数

## 什么是驱动传参

驱动传参就是传递参数给我们的驱动。举例:
insmod beep.ko a=1

## 驱动传参数有什么作用呢?

- 设置驱动的相关参数，比如设置缓冲区的大小

- 设置安全教研，防止我们写的驱动被人盗用

## 怎么给驱动传参数?

- 传递普通的参数，比如char,int类型的函数:

  ```
  module_param(name, type, perm);
  ```

  

- 参数:
- name要传递进去的参数的名称
- type:类型
- perm:参数读写的权限

### 传递数组函数

```
module_param_array(name, type, nump, perm)
```

- 参数:
- name要传递进去的参数的名称type:类型
- nump:实际传入进去的参数的个数

## 如果我们多传递进去参数，会发什么什么?会报错

### 代码

```
#include <linux/init.h>
#include <linux/kernel.h>
#include <linux/module.h>

static int a;
static int b[5];
static int count;
module_param(a,int,S_IRUSR);
module_param_array(b,int,&count,S_IRUSR);

static int hello_init(void){

    printk(KERN_ALERT "Hello , World\n"); //内核空间里没有printf，用printk
    printk("a = %d \n", a);
    printk("count = %d \n", count);
    int i;
    for (i = 0; i < count; i++)
    {
        printk("b[%d] = %d \n",i,b[i]);
    }
    
    return 0;

}

static void hello_exit(void){
    printk(KERN_ALERT "Goodbye , World\n");
}

//模块的注册
module_init(hello_init);
//模块的卸载
module_exit(hello_exit);
MODULE_LICENSE("Dual BSD/GPL");
```
### 输入命令
```
insmod parameter.ko b=1,2,3,4,5
```
