# swift 命令

> main.swift

```Swift

    import Foundation

    func addTwoNum(num1: Int, num2: Int) -> Int {
        return num1 + num2
    }

    let sum = addTwoNum(num1: 1, num2: 2)

    print(sum)
    
    
```

> 通过llvm编译生产.o 文件

*   swiftc -o main.out main.swift

> 生成 ast 命令

*   swiftc main.swift -dump-ast

> 生成sil

*   swiftc main.swift -emit-sil

> 中间层

*   swiftc main.swift -emit-ir
