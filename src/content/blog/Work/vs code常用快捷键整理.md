# VS Code 常用快捷键整理

> 说明：以下以 macOS / Windows(Linux) 两种按键形式展示。  
> Windows 和 Linux 大多数情况下快捷键一致。

## 1. 全局与基础操作

| 功能               | macOS                                     | Windows / Linux            |
| ------------------ | ----------------------------------------- | -------------------------- |
| 打开命令面板       | `Cmd + Shift + P`                         | `Ctrl + Shift + P`         |
| 打开设置           | `Cmd + ,`                                 | `Ctrl + ,`                 |
| 打开键盘快捷键设置 | `Cmd + K` 然后 `Cmd + S`                  | `Ctrl + K` 然后 `Ctrl + S` |
| 切换侧边栏         | `Cmd + B`                                 | `Ctrl + B`                 |
| 切换面板           | `Cmd + J`                                 | `Ctrl + J`                 |
| 打开终端           | `Ctrl + \`` | `Ctrl + \``                 |                            |
| 新建终端           | `Ctrl + Shift + \`` | `Ctrl + Shift + \`` |                            |
| 打开扩展           | `Cmd + Shift + X`                         | `Ctrl + Shift + X`         |
| 打开资源管理器     | `Cmd + Shift + E`                         | `Ctrl + Shift + E`         |
| 打开源代码管理     | `Ctrl + Shift + G`                        | `Ctrl + Shift + G`         |

| 功能                | macOS             | Windows / Linux    |

| 保存文件            | `Cmd + S`         | `Ctrl + S`         |

| 打开最近文件/工作区 | `Ctrl + R`        | `Ctrl + R`         |

| 删除行尾空白             | `Cmd + K` 然后 `Cmd + X`     | `Ctrl + K` 然后 `Ctrl + X` |

## 9. 常用建议

- 先熟悉 `Cmd/Ctrl + Shift + P`，它是 VS Code 最重要的入口之一。  
- `Cmd/Ctrl + P` 用来快速打开文件，日常使用频率很高。  
- `Cmd/Ctrl + D` 和 `Cmd/Ctrl + Shift + L` 适合批量修改重复内容。  
- `Shift + Alt + F` 是最常用的代码格式化快捷键。  
- 快捷键可以在 VS Code 的键盘快捷键设置中自定义。  

## 10. 设置建议

```json
{
  "editor.formatOnSave": true,
  "editor.formatOnPaste": true,
  "files.autoSave": "afterDelay"
}
```

## 11. 备注

- 不同操作系统、键盘布局和插件可能会影响部分快捷键。
- 如果快捷键冲突，可以在 **Keyboard Shortcuts** 里查看并修改。
- VS Code 官方支持查看、修改和导出完整快捷键配置。[page:2]
